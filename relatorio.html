9. Limitação dos Dados

Honestidade epistemológica.

FONTES: Dados pré-compilados de fontes públicas: IBGE, INEP, VIGISAN, DataSUS, BCB, TSE, FBSP, PRODES/INPE, CONAB, SNIS.

SCORES DE POLÍTICOS: OPINIÃO ESTRUTURADA, não FATO. Passa em 0.5/7 critérios do Gate Epistemológico. Os inputs (fez_funcionar=0.9, liderou=0.8) foram atribuídos sem fonte externa verificável.

PROPOSTAS DE SAMARA: SIMULAÇÃO. Os dados de execução (COMO, CUSTO, PRAZO) foram preenchidos pelo OpenRepublic, não pela candidata. Não passam pelo Gate Epistemológico.

GATE WO: O sistema confunde acesso a dados com qualidade de proposta. Quem tem equipe técnica detalha execução. Quem não tem, não. O método de 3 camadas (diagnóstico + direção + execução) corrige parcialmente esse viés.

PARA VIRAR FATO: Triangulação de 3+ fontes independentes + auditoria pública + dados abertos em CC0 + reprodução por terceiros.
