## 1. MARCO LEGAL NECESSÁRIO

### 1.1 Leis federais a aprovar

**Lei dos Dados da República (nova)**
- Declara dados gerados em território nacional como bem público quando coletados por empresas com receita > R$ 50 mi/ano
- Obriga portabilidade universal e deleção imediata a pedido
- Cria Fundo Nacional de Dados para financiar IA pública

**Reforma da LGPD**
- Transforma ANPD em agência autônoma com poder de sanção criminal
- Proíbe transferência de dados sensíveis para fora do país sem autorização da assembleia

**Portarias**
- Portaria que obriga todas as plataformas com >1 milhão de usuários a publicar APIs de exportação de dados em formato aberto

## 3. FASES DE EXECUÇÃO

### FASE 1 — LEGALIZAÇÃO (Anos 1-2)

**3.1.1 Censo Nacional de Dados**
- Mapeamento de todos os repositórios de dados de empresas > R$ 50 mi
- Identificação de 180 milhões de brasileiros com dados explorados comercialmente

**3.1.2 Criação da Agência Nacional de Dados**
- 3.000 servidores concursados
- Laboratórios de auditoria de algoritmos em 5 capitais

**3.1.3 API de Portabilidade Obrigatória**
- Todas as plataformas devem oferecer exportação em 48h
- Padrão OpenData Republicano (ODR)

### FASE 2 — INFRAESTRUTURA (Anos 3-5)

- 5 data centers soberanos de 100 PB cada
- Treinamento de modelo de IA pública brasileira (OpenGPT-br) em dados anônimos
- Sistema de deleção automática de dados após 5 anos (salvo consentimento renovado)

### FASE 3 — SOBERANIA (Anos 6-7)

- 100% dos dados críticos sob controle público ou cooperativo
- IA pública brasileira entre as 5 mais usadas no mundo
- Royalties de dados distribuídos via OpenCredit para todos os cidadãos
